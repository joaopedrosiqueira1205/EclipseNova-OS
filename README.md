\# SolarNexum OS ☀️



SolarNexum OS é uma distribuição Linux em desenvolvimento,

projetada para ser leve, rápida e eficiente.



\## Objetivos



\- Baixo consumo de RAM

\- Bom desempenho em computadores modestos

\- Interface simples e rápida

\- Compatibilidade com aplicativos Linux

\- Foco em jogos

\- Sistema gratuito e open-source



\## Versão



SolarNexum OS 0.1 - Em desenvolvimento
