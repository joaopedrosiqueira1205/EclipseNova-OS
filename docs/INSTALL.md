# Instalação

A primeira versão deve ser testada em máquina virtual.

O instalador automático permanece deliberadamente não destrutivo até:
1. a ISO inicializar;
2. rede e armazenamento funcionarem;
3. boot BIOS/UEFI ser testado;
4. recuperação de erro ser testada.

Não use comandos de particionamento automáticos em um computador com dados importantes.
