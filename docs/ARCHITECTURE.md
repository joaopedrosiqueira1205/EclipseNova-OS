\# SolarNexum OS Architecture



SolarNexum OS é uma distribuição Linux independente.



\## Fundação



\- Linux Kernel

\- GNU C Library (glibc)

\- GNU Toolchain

\- systemd

\- arquitetura x86\_64



\## Método de construção



O desenvolvimento inicial segue os princípios do

Linux From Scratch (LFS).



O SolarNexum OS não utiliza Debian, Ubuntu, Arch

ou outra distribuição como base do sistema final.



\## Objetivos



1\. Alto desempenho

2\. Baixo consumo de recursos

3\. Estabilidade

4\. Segurança

5\. Compatibilidade

6\. Sistema completo para desktop



\## Hardware inicial



A primeira versão será otimizada e testada

principalmente no Lenovo IdeaPad S145-15IIL.



Posteriormente o suporte será expandido para

outros computadores x86\_64.
