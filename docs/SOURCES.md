\# SolarNexum OS - Source Policy



O SolarNexum OS e uma distribuicao Linux independente.



\## Principios



Os componentes do sistema sao construidos a partir

de seus respectivos projetos upstream.



O Linux From Scratch e utilizado como referencia

tecnica para o processo inicial de bootstrap.



SolarNexum OS nao utiliza pacotes binarios do

Debian, Ubuntu, Arch ou outra distribuicao como

base do sistema final.



\## Verificacao



Downloads utilizados pelo sistema de build devem

ser verificados antes da compilacao.



O sistema de build devera validar checksums e

interromper a compilacao caso um arquivo esteja

corrompido ou tenha sido modificado.
